El color comunica antes que las palabras

Cada color transmite algo: el azul da confianza, el rojo urgencia, el verde «todo bien». Elegir bien los colores de una app no es cuestión de gusto, es cuestión de qué quieres que sienta quien la usa.

Qué transmite cada color

Estas asociaciones son bastante comunes en la cultura occidental. No son leyes fijas (dependen del contexto y del país), pero te sirven de punto de partida.

local_fire_department

Rojo

Urgencia, pasión, peligro, energía. Altamente estimulante, incrementa el ritmo cardíaco.

Uso Común:
Errores, comida rápida, descuentos (CTA).
water_drop

Azul

Confianza, seguridad, calma, profesionalismo. El color más universalmente preferido.

Uso Común:
Bancos, corporativo, redes sociales, salud.
eco

Verde

Crecimiento, naturaleza, salud, éxito, dinero. Muy relajante para el ojo humano.

Uso Común:
Finanzas, eco-friendly, confirmaciones (éxito).
lightbulb

Amarillo / Naranja

Optimismo, juventud, precaución, creatividad. Capta la atención rápidamente.

Uso Común:
Alertas (warnings), e-commerce, infantil.
psychology

El contexto lo cambia todo

Un mismo color encaja o desentona según de qué vaya la app. Fíjate cómo cada tipo de producto elige su paleta para transmitir lo que le interesa.

account_balance Finanzas

App Bancaria

Prioriza la seguridad y estabilidad mediante tonos fríos y profundos. Evita el rojo (asociado a deudas).

restaurant Gastronomía

Delivery / Restaurante

Utiliza colores cálidos que estimulan el apetito y sugieren rapidez. El rojo y el amarillo son la norma.

medical_services Salud

Salud y Bienestar

Tonos limpios (verdes, turquesas, blancos puros) que sugieren higiene, curación y tranquilidad.

code

Del color al código

No se usan colores sueltos: se les da un rol. En vez de escribir #3B82F6 por toda la hoja de estilos, se guarda una vez con nombre y se reutiliza. Así, si cambias el color de marca, cambia en toda la app de golpe.

  • Primario: el color de la marca. Cabeceras, enlaces.
  • Acento: reservado para la acción principal (un botón por pantalla).
  • Semánticos: verde = éxito, rojo = error, amarillo = aviso.
  • Neutros: grises para fondos, bordes y texto secundario.
/* se define una vez... */
:root {
  --color-primario: #182442;
  --color-acento: #62fae3;
  --color-error: #ba1a1a;
}
/* ...y se reutiliza en todas partes */
.boton-principal { background: var(--color-acento); }
